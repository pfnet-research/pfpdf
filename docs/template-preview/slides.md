# 書き方

## 1 枚のスライド

### 題名のすぐ下の ### はサブタイトルになります

`##` の見出しが、新しいスライドの題名になります。日本語、English、数字 0123456789 を含めて、文字の大きさと行間を確認します。

- 箇条書きの 1 項目め
- **強調**と `inline code` を含む 2 項目め
  - 入れ子の項目

::: note
注記は、スライドの下に小さく表示します。

::: talk
TALK-MARKER 発表者ノートは PDF に表示しません。

## 列を並べる

### 同じ名前の欄は左から順に並びます

::: column
### 変更前

処理に 12 ms かかっていました。

::: column
### 変更後

処理は 10 ms になりました。

::: column
### 差

約 17% 短くなりました。

::: note
値は 30 回の計測の中央値です。

## 情報の多いスライド

<!-- pfpdf:font_size=20 -->

### font_size=20 で本文を小さくします

- 題名とサブタイトルは、そのままの大きさです。
- 本文の基準を 20 pt にします。表、コード、注記も基準に合わせて変わります。
- 原稿全体を小さくするときは、フロントマターに `font_size: 20` のように書きます。
- 1 枚に収まらないスライドがあると、変換はエラーで止まります。

::: note
文字を小さくする前に、スライドを分けることも検討してください。
